# AI assistance, verification and review

The goal is a community-maintained mathematical library for organizational models.
AI assists specification, theorem search, proof drafting and adversarial review.
Human researchers judge source interpretation and proposed community interfaces.

The demonstrated workflow identifies exact sources, separates prose/equations/active
code, specifies canonical data, constructs adapters, proves reusable results, checks
explicit inputs against source evaluators, then challenges inheritance claims with
invariants and counterexamples. See [source correspondence](SOURCES.md) and
[theorem coverage](THEOREMS.md).

A key distinction is deterministic inclusion versus stochastic inheritance. The
shared cyclic landscape is canonical NK, while sharing a sampled table gives a
different law from sampling a table per locus independently. A numerical witness
alone does not establish the continuous-law result.

Lean checks consequences of the chosen definitions. Axiom guards, source audits and
R comparisons provide distinct evidence; none certifies the whole original simulation
or the scientific meaning of a definition. Exact generation settings and intermediate
AI prompts were not retained for replay. Reproducibility concerns source, proofs
and computation. Current checks are in [CHECKS.json](CHECKS.json).

Independent agent reviews checked statement preservation, source correspondence,
naming and packaging. Human decisions remain pending, as explicitly requested:
